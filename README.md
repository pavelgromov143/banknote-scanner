# Banknote Scanner

Автоматическое распознавание номинала и серийного номера российских купюр с фотографии.

>  **Ограничение текущей версии**: скрипт обучен и протестирован **на небольшом датасете только современных 100 рублевых банкнот** (образца 2022 г.). На других номиналах и старых банкнотах модель YOLO не детектирует номер, и обработка завершится с сообщением «серийный номер не найден». Поддержка остальных номиналов — в планах.

>  **Рекомендация по съёмке**: фотографируйте купюру **без наклона** — плоско, сверху, чтобы серийный номер был параллелен краю кадра. Небольшой поворот (до ~10°) выравнивается автоматически, но при сильном наклоне банкноты в кадре (перспектива) точность OCR заметно падает.

## Как это работает

1. **Детекция (YOLOv8)**. Модель находит на фото номинал (класс `rub-XXX`) и все области с серийным номером (класс `number`, порог уверенности 0.2). Если номеров несколько — обрабатываются все.
2. **Приоритезация кропов**. Номера сортируются: сначала вертикальные, затем остальные
3. **Выравнивание (OpenCV)**. Вертикальные кропы поворачиваются на 90°, наклон компенсируется по углу контуров текста (`warpAffine`). Небольшой наклон (< 10°) не трогается.
4. **Препроцессинг + OCR**. Кроп увеличивается в 4 раза, переводится в цвета серого, размывается и бинаризуется адаптивным порогом. EasyOCR распознаёт символы.
5. **Постобработка (Regex)**. Латиница переводится в кириллицу (`A`→`А`, `B`→`В`, …), типичные ошибки OCR фиксятся (`O`→`0`, `З`→`3`, `S`→`5`). Итог проверяется по маске `2 буквы + 7–9 цифр`.
6. **Выбор результата**. Первый кроп, прошедший маску, побеждает. Если ни один не прошёл — берётся наиболее близкий по длине к 11 символам (2 буквы + 9 цифр), при равенстве — вертикальный и с более светлым фоном.
7. **Сохранение**. Результаты по файлам записываются в `output/results.csv` (колонки: `file`, `nominal`, `raw_ocr`, `serial`, `valid`).

## Результаты
* Обучение YOLOv8 на собственном датасете: **mAP50 = 0.86**.
* Точность распознавания OCR на тестовых фото: **~80%**.

## Стек
`Python` `PyTorch` `Ultralytics (YOLOv8)` `OpenCV` `EasyOCR`

## запуск
1. Установите зависимости: `pip install -r requirements.txt`
2. Положите тестовые фото в папку `output/test_images/`.
   **Желательно, чтобы купюра была сфотографирована без наклона** — ровно, сверху, с хорошо видимым серийным номером.
3. Запустите скрипт:
```bash
cd src
python main.py
```
